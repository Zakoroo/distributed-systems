# Go fundamentals

Parent: [Concepts](../README.md).

Read these notes in order if Go is new to you. Each explains a small set of ideas
without depending on the current application design.

1. [Values, types, and control flow](values-and-control-flow.md): declarations,
   slices, maps, structs, pointers, methods, loops, and conditions.
2. [Functions, interfaces, and generics](functions-and-types.md): callbacks,
   closures, type parameters, and how components fit together.
3. [Errors and cleanup](errors-and-cleanup.md): return values, `nil`, wrapping,
   `defer`, and resource ownership.
4. [Modules, packages, and command-line arguments](modules-and-cli.md): project
   organization, imports, workspaces, building, and parsing a port.
5. [Testing and evidence](testing.md): tests, test doubles, race detection, and
   the difference between a passing check and a performance claim.
6. [Regular expressions](../regex-basics-in-go.md): reading text patterns, groups,
   and Go's matching API.
